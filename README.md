# Shortest Path Finder

## Overview

This project was developed as part of the Data Structures course.

It implements a graph-based shortest path system in C that finds routes between cities using Dijkstra's Algorithm and Breadth-First Search (BFS). A Min Heap is used to optimize Dijkstra's algorithm, and the program compares the execution time and results of both algorithms.

---

## Features

- Load graph data from file
- Find the shortest path using Dijkstra's Algorithm
- Find the shortest path using Breadth-First Search (BFS)
- Compare execution time between algorithms
- Display complete route details
- Save shortest path results to a file
- Graph representation using Adjacency Lists
- Min Heap implementation for efficient priority queue operations

---

## Algorithms

- Dijkstra's Algorithm
- Breadth-First Search (BFS)
- Min Heap
- Adjacency List Graph Representation
